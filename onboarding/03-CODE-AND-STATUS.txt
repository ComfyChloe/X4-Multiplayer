THE MODEL
Host X4 supplies the simulated world. The Python server authenticates, routes and
validates selected state/transactions; it does not simulate an X4 universe itself.
Guest X4 loads the host's pristine starting snapshot, then applies supported live
state while other engine behavior can still diverge. A numeric random seed alone
did not align the initial stations. Restart currently returns to the starting
world, not a saved played campaign. Two simultaneous players are implemented.
