FOCUSED CHECK — STATIONS / SHARED START / HOSTING
1. Confirm the guest downloads the world and reaches its own Shuttle. Note either
   an installer/transfer error, a permanent loading screen or a remaining Pause
   state. Check your personal resolution and bindings have been retained.
2. Pick an ORDINARY station in Argon Prime. Compare its code/name, map location,
   orientation and nearby landmarks on both PCs. Both fly to the SAME station.
   Have one player dock while the other observes: does the ship sit on the actual
   station on both sides, instead of in empty space? Capture both views if not.
3. Repeat with one ordinary station in another sector. This checks layout beyond
   the starting sector; it does not prove a shared ongoing economy.
4. Stop BOTH games and the relay. Restart the relay and both games. Both must load
   the same starting layout again. Previous gameplay progress is expected to reset.
5. If possible, swap host OS for a separate session using fresh package folders.
   Report Windows-host server/transfer/start behavior separately from Linux-host.

No need to repeat the complete cargo/radar/Cooperative Trial suite already passed
by humans. Report regressions if encountered while doing the station test.
Weapons/general NPC combat have no new acceptance claim in this version.

KNOWN LIMITS
- The starting save is shared; new station construction/destruction, economy,
  production and arbitrary NPC orders are not yet continuously synchronized.
- Persistent multiplayer save/resume, late join to progressed worlds, ordinary
  shared missions and ingame text chat remain unfinished.
- The protected Mercury service freighter is not a general fleet-command test.
- Full docked-child/parent synchronization and projectile equivalence remain open.
- A previous guest cannot continue independently or resume an old relay epoch.

After a failure, run4-DIAGNOSTICS on BOTH PCs before another launch. Include the
host server logs, the exact error, roles/OS, approximate time, sector and station
code. Do not post session credentials. Keep the previous release ZIPs unchanged.
