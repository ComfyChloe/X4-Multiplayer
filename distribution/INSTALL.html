New: Windows hosting, portable runtimes, private group invitations and corrected Shuttle sensor initialization. Still incomplete: the shared universe, ordinary stations, NPC orders/damage and vanilla missions. Both launchers still create separate worlds. Read NEXT-TEST.txt for tonight's short test.

1 · Requirements and upgrade

Both PCs need X4 9.00 (611726), Steam build 23660954, matching official DLC including Timelines, and this exact mod version. Disable Ventures and other third-party mods for this test. Linux uses native X4, not Proton. The Windows package is x64. Python and the relay are included; setup requires no runtime download.

Extract the complete ZIP for your OS into a fresh folder. Close both games and the previous server. Run 5-REMOVE-MOD from the OLD package before installing the new one. Existing installations are not silently overwritten. Keep old archives for rollback.

2 · Choose a host and join its session

  1. Host, on either OS: run 1-INSTALL, choose H, and enter your LAN/ZeroTier IPv4. Use an address reachable by the guest, not localhost. Installation writes a private JOIN-SESSION.json in the package folder. Send that file privately to the guest.
  2. Guest, on either OS: run 1-INSTALL, choose G, and enter the path to the received JOIN-SESSION.json. The launcher rejects mismatched versions and public-test invitations.
  3. Host: run 2-START-SERVER. Keep its console open. Guest: run 2-TEST-CONNECTION. A successful connection check does not occupy a player slot.
  4. Both: run 3-START-X4-TEST to start a fresh creative test world. Stay in the pilot seat until setup completes.

Windows: double-click the numbered .cmd files. Linux: open a terminal in the extracted folder and run, for example, bash 1-INSTALL.sh. Use another terminal to start the game while the server runs.

The host must also run X4. The Python server routes shared state; it is not a headless universe simulator. Each session has one host player and one guest. Separate pairs can create separate invitations. A new session needs a fresh extracted package; setup will not replace an existing session or installed configuration.

3 · Network

Both PCs need a reachable LAN or approved ZeroTier connection. Allow UDP 45841 to the host through its firewall only if necessary. On Windows, allow the included Python server on the private network you use for testing; do not disable the firewall. No router forwarding is needed for a working ZeroTier connection. Public Internet hosting is outside this test.

4 · Isolated game profile and test

Only profile 45841 is used. Autosave is disabled; a profile containing saves is refused. Never load or save a normal game with this experimental mod. Both Shuttles have six guns, Mk3 thrusters and all six software modules including Docking Computer Mk2.

The Linux profile uses 1920×1080 fullscreen, Low settings, High textures, shader quality 1 and a 60 FPS limit. Windows keeps Low textures and shader quality 2. Previous changed profile settings are backed up. The Linux settings are a measured local startup workaround, not an NPC PiP or general performance fix.

Follow NEXT-TEST.txt first: nearby radar/HUD, ship motion/names, ordinary cargo magnet in both directions, and the custom Cooperative Trial. WORLD-SYNC-TEST.txt gives the longer regression sequence. The Mercury service freighter has protected hull and is not a supported multiplayer NPC command target.

The custom trial requires selling a combined 20 Energy Cells at LAN Trading Station Beta, then destroying both LAN Targets. It rewards the shared treasury once. It does not make normal vanilla missions cooperative. Do not treat independent ordinary station positions or NPC commands as fixed.

5 · Diagnostics, stop and removal

Run 4-DIAGNOSTICS on BOTH PCs before starting another attempt. Keep both game logs and the host's server logs. Report version, host/guest OS, sector, object name/code, approximate time and action. Generated session files contain credentials; do not post them publicly.

7-VERIFY-PACKAGE verifies archive-file hashes; configured role files are checked separately. Ctrl+C in the server console stops the relay. If either game or the relay is restarted, both players start fresh worlds. Multiplayer save/rejoin is not supported.

To remove: close X4 and run 5-REMOVE-MOD from the package that owns the installation. It archives only its owned mod; normal saves are untouched. The test profile is retained. Restore your normal mods before loading normal saves.
