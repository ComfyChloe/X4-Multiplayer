X4 LAN Lab version numbering

Format: MAJOR.MINOR.PATCH, for example 5.0.1.
- MAJOR: a new major development stage or incompatible multiplayer changes.
- MINOR: new features within that stage.
- PATCH: fixes, defaults, documentation and packaging improvements.
Every published update gets a higher version, including launcher-only fixes.

Where to see the version:
- ZIP and extracted folder names: X4-LAN-7.1.2-Linux / Windows11.
- VERSION.txt and package.json inside each package.
- Launcher output, server dashboard/status log and installed mod display name.

Use both archives from the same release folder. Each newly built pair has a shared
session key; identical version labels alone do not make separate builds a pair.
Exception: the 5.0.2 Windows launcher-only update preserves the existing pair.
After that small update, the folder name and installed mod display name keep
their previous label; VERSION.txt and the launcher show the updated version.
This is the mod/package version, not the X4 game version (currently 9.00).

Development:
The source VERSION.txt is the canonical package version. The package builder
reads it and stamps file/folder names, VERSION.txt, package.json, user guides and
the mod display name. Update the changelog and this release map when advancing it.
X4 content.xml's integer version is its separate engine compatibility revision;
do not put a dotted package version in that XML attribute.
