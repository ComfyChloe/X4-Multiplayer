HEALTH FUNCTION PROBE: SYNTHETIC-PEER PHASE CONTRACT (dev only, PR #36)
Scope: one native Linux HOST (p1) against a synthetic p2 peer, isolated owned profile, disposable
world. It covers host-side code only: relay generations, HBASE/HACK/HEALTH, host Apply/Release,
the 2% floor, the life tick and the watchdog. It gives NO guest-native coverage: guest Base, the
keepalive watchdog and the bubble guards need a native guest. Not gameplay acceptance.

INSTALL (harness)
Client config of the host: coop=true, fire2=true, pilot_health=true, health_probe=true,
test_profile="45841" (owned isolated profile). Copy dev/health_function_probe.lua into ui/,
registered AFTER ui/health_game.lua, and dev/health_function_probe.xml into md/.
Everything else is unchanged. Evidence: the host debug log lines
  [X4LAN] HEALTH_PROBE ...   (samples at 5 Hz, op sequence, frames, drops)
  [X4LAN] HEALTH_* / SHIP_LETHAL / SHIP_DESTROYED   (production lines)
plus the relay transcript of the synthetic peer.

SYNTHETIC PEER (p2), using the existing guarded controller
- HELLO as p2; CREW piloting entity 2 (controlled=aboard=2). Keep NAV2 for ship 2 at a fixed pose
  near the host ship (stationary is enough). No FIRE2 is needed except in optional phase 3b.
- Read HGEN|1|lease|rev|g1|g2 and HBASE|1|lease|2|gen|hull|shield from the relay.
- Send HACK|1|lease|2|gen once per received HBASE of the generation it adopts.
- Send HEALTH|1|lease|2|gen|seq|hull|shield at 10 Hz with seq = phase * 1000 + n (n >= 1,
  increasing). The probe reads the phase from the seq.

PHASES (seq ranges) with PASS criteria from the log
1  Handover (no HEALTH yet). Wait for HGEN and HBASE of gen G, then send HACK G.
   PASS: no op=Apply before the first HEALTH. The HBASE hull/shield equal the host WORLD values
   of ship 2.
2  Authority, seq 2001..2050 (5 s), hull 90, shield 50.
   PASS: op=Apply gen=G for each frame; samples entity=2 live=true gen=G hull ~= 90 (+-0.5),
   shield ~= 50; never a SHIP_LETHAL.
3  Host-only proxy damage under authority, seq 3001..3050, same values. The probe drops the proxy
   hull to 1.5% on every tenth accepted frame.
   PASS: each 'drop' readback >= 2 (floor), and the next samples are back at 90 within 0.2 s;
   no SHIP_LETHAL.
   3b (optional): host ship 1 fires real FIRE weapons at the proxy, with the same criteria.
4  Expiry and rebase. Stop HEALTH for 3 s. Then send old gen G seq 4001 hull 90, then wait for the
   new HBASE G' > G, HACK G', HEALTH G' seq 4002.. hull 80.
   PASS: after 0.75-1 s an HGEN with g2 = G' (relay) and/or op=Release closed=true gen=G; samples
   live=false closed >= G with hull back at 90 (canonical); the G seq 4001 frame accepted=false
   with no Apply; HBASE G' carries the host WORLD value; op=Apply gen=G' only after HACK G'.
5  Queued / stale work and re-entry. Send HEALTH G' seq 5001..5005, then within 50 ms CREW leave
   (controlled=0) and CREW re-enter (controlled=2) WITHOUT waiting for a snapshot, then HEALTH G'
   seq 5006.
   PASS: op=Release closed=true gen=G' right after the AUTH transition; 5006 accepted=false; a new
   generation G'' in HGEN/HBASE; no Apply of G' after its Release. Then HACK G'' and HEALTH G''
   seq 5007.. hull 70 are accepted.
6  Legitimate lethal. HEALTH G'' seq 6001 hull 1.0 shield 0.
   PASS: op=Apply hull=1.0, then HEALTH_LETHAL, SHIP_LETHAL slot=2 and SHIP_DESTROYED slot=2 within
   0.2 s. Later frames get no further Apply (dead or not operational). Samples dead=true.
7  Watchdog (optional, needs a way to stop the host's Lua frame without stopping MD; skip if not
   available): MD HEALTH_WATCHDOG after 2 s, closed >= gen, Expired -> HSTALE, rebase as in 4.

FAIL conditions: any Apply of a closed or older generation; hull below 2% under authority other
than phase 6; a resumed old generation after expiry; SHIP_LETHAL outside phase 6; probe or
production 'STOPPED' / MD errors.
