The native controller cycle is qualified separately on PR26. This branch owns
the opt-in Lua/native adapter and execution-time guards. Claude retains independent
review of PR25, PR21 importer and PR26 evidence after01:00; no duplicate assignment.

The adapter must admit observations only through the authenticated session client
and a committed saved-ship identity map. Native saved indices name both ship and
dock; remote process handles are never accepted. Every ship binding rechecks fresh
host metadata and protected player ancestry. A guest retains native docked-parent
transforms and permits pose/sector writes only after a fresh FREE observation,
no queued/inflight attachment work and confirmed native FREE state.

Before an asynchronous native mutation, a local prepare/consume exchange validates
saved references, current identity/attachment, target witness/compatibility,
occupancy/reservation and player ancestry. Native operations have monotonic local
IDs; consuming a denied operation cannot later mutate or be reused. Explicit
controller requires_ack mode prevents an early matching state from releasing an
unconsumed operation. Only an exact native no-mutation rejection permits retry;
a missing reply remains an unknown outcome and retains its fence.

Execution freshness design under qualification: the native prepare records the
local full calendar second (player.systemtime with standard strftime fields) and
game age. Consumption requires the same second, a nondecreasing game age within
one second, and an unpaused engine. The Lua callback may enqueue consumption only
with at least1.25s left on its2s observation lifetime. Native checks run again at
consumption, and a crossed window produces an explicit no-mutation rejection.
This avoids treating simulation age alone as real elapsed time during pauses.
The clock/queue behavior still requires native evidence before use, especially
pause/resume and boundary rejection. No engine timing acceptance is inferred from
schema validity or a mock. A changed system clock is not a supported test condition.

Host observation scheduling must also fit the admitted4096-ship/2s receiver bound;
relay fairness alone does not prove native publisher capacity. Baseline/view/lease
changes revoke pending capabilities without dropping already issued readback fences.
Source will stay unregistered/disabled until the bounded path is reviewed and
native behavior demonstrated. Ordinary missions remain medium priority; ingame
chat remains conditional low priority behind the shared-universe work.
