BOUNDED PRIMITIVE
dev/dock_state_probe.lua/.xml reads the macros of a non-player carrier and stored
child, then creates an empty diagnostic carrier and child far from normal traffic.
Original NPCs are left untouched. It selects exact native internal/external dock
references on that new carrier, suspends only the diagnostic pair and holds the
carrier transform. Six phases are measured:
0 initial internal storage;1 spawn on the selected external pad;2 request storage;
3 spawn on the same external pad;4 undock;5 spawn in the original internal bay.
Each phase requires Lua and MD readbacks using unchanged native ship handles.
The MD read acknowledgment must arrive before the next action. Requests are
sequential, bounded to30 seconds per phase, and reject stale phases, protected
ships or other occupants/reservations. The fresh disposable world is discarded
without saving. This opt-in probe has no shipping UI entry or network protocol.
