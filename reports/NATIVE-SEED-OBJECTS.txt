CURRENT IMPLEMENTATION
The seed marker now retains an MD list of native ship references in the pristine
snapshot. Both peers import that SAME saved list in bounded batches after native
admission; engine reload resolves each saved reference to the local component.
Its list index is the shared object ID. Human-readable ship codes are metadata,
not lookup keys: native testing proved they can collide across the universe.
Original equipment, pilots and engine references remain on the original ships.

Explicit seed_binding=true requires the verified pristine snapshot and its
versioned object registry. Missing/incompatible registries, replaced references,
changed authority epochs/descriptors and protected player/service objects fail
closed. No native original is deleted merely because a sector view omits it.
The guest suspends local ship simulation, applies host poses and uses guarded MD
warps across sector parents. It repairs native pose drift even if the received
target is unchanged. Player-owned ships are included except co-op/service objects.
Host-created ships use IDs above the reserved seed range and remain unresolved
until the subsequent lifecycle/descriptor implementation; no visual fallback is
used to pretend their native data is synchronized.
