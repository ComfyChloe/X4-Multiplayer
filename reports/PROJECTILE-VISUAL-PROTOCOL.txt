OBSERVED PROJECTILE VISUALS — OPT-IN CONTRACT — 24 OCTOBER 2026

INERT FOUNDATION. This channel may create only temporary harmless visuals.
It never establishes a hit, grants damage, aims a real gun, or changes gun heat.
Existing SHOT/capture/HEALTH authorities remain separate. A native source records
actual locally piloted original projectiles, including native aim/spread/cadence.
The receiver renders those observations against its existing source-clock motion
buffer. No selected-target substitution. Only the three already admitted stock
uniform unmodified weapon types are in initial scope.

BEND|1|lease|entity|epoch|gen|id|time

BOUNDARIES
ASCII, maximum768 bytes; exact field count/direction; no embedded newline/pipe.
Leases: existing32-character lowercase hexadecimal lease format.
entity1..2. epoch,gen,id are integers1..2147483647. id is a per-generation projectile
identifier, not a native X4 handle. time is sender's monotonic source-clock seconds,
finite0..1e12, matching NAV2 time domain. sector uses the existing ATOM grammar.
kind:1=stock X Shuttle plasma,2=generic pulseMk1,3=generic pulseMk2.
Position bounds: absolute value<=50000000 metres. Velocity components<=100000m/s.
Angles are radians, each absolute value<=2*pi. ttl is finite, greater than0 and
at most3 seconds. All numeric fields must be finite. A floating lexical value is
not accepted for an integer field. Do not infer health-generation validity from
successful packet decoding.
