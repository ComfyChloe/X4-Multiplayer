# Repository policy

This repository is a curated source-inspection mirror. Its purpose is reading
and downloading unchanged source, subject to [LICENSE.txt](LICENSE.txt).
It is not the private development repository and has no automatic synchronization
with private branches, pull requests, issue discussions or test evidence.

Visitors do not receive collaborator/write access. Publication and later updates
are performed by the owner from reviewed snapshots. A fork is an independent copy;
it does not permit changing this repository, and it does not grant additional
reuse rights beyond GitHub's applicable terms and the license.

Unsolicited code contributions are not accepted through this mirror at present.
Contact the owner before contributing or requesting additional usage permission.
Do not assume that a public source repository authorizes running experimental
installers or using normal game profiles for tests.

Each update should preserve the previous published snapshot in this repository's
own history. Never push or merge private development history into this mirror.
